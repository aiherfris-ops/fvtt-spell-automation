# Spell Automation

Автоматизация заклинаний **dnd5e** в Foundry VTT: исправляет импорт Plutonium и добавляет механику,
которой в данных нет, — множественные снаряды, эффекты, карточки урона, инструменты ГМа.

## Требования

- Foundry VTT 14
- dnd5e 5.3.x
- **midi-qol 14.6+ обязателен** (эта ветка собрана под него)
- Необязательно: Sequencer и JB2A (анимации круга телепортации)

## Заклинания

Ниже — все заклинания, которых касается модуль, и что именно он делает.

- **Alter Self** — Скорость плавания = скорость ходьбы; при выборе нового усиления прежнее снимается.
- **Ectoplasmic Trail** — Шлейф до конца хода: существа на пути покрываются эктоплазмой (−10 футов, 2d8 некротического урона в начале хода).
- **Eldritch Blast** — Число лучей по уровню персонажа, отдельный бросок атаки на каждый луч.
- **Faerie Fire** — Атаки по подсвеченным существам — с преимуществом.
- **Goodberry** — Создаёт предмет с 10 ягодами, которые исчезают через 24 игровых часа.
- **Greater Restoration** — После сотворения — выбор, что снять с цели: 1 уровень фактического истощения, Очарован, Окаменел; проклятие и уменьшения — отметкой.
- **Healing Word** — Время накладывания — бонусное действие.
- **Heat Metal** — Сотворение и «Раскалить снова» — урон всегда, помеха при проваленном спасброске; повтор без траты ячейки, с кругом сотворения.
- **Hunter's Mark** — +1d6 силовым полем при попадании атакой по отмеченной цели (через общий бонус урона Midi).
- **Jim's Magic Missile** — Атака на каждый снаряд, крит 5d4, откат на натуральной 1.
- **Lesser Restoration** — После сотворения снимает с цели выбранное состояние: ослеплён, оглох, парализован или отравлен.
- **Magic Missile** — Распределение дротиков по целям вместо одного броска на всех; учитывает Shield.
- **Mirror Image** — Эффект с тремя копиями; попадания по носителю проверяются бросками d6.
- **Ray of Sickness** — При попадании — отравление до конца следующего хода заклинателя (версия 2024).
- **Scorching Ray** — Распределение лучей по целям, отдельный бросок атаки на каждый луч.
- **Shadow Blade** — Создаёт оружие-клинок (зависит от концентрации) с атакой «из тени» с преимуществом.
- **Shield** — Время накладывания — реакция (в импорте было действие); используется Magic Missile для обнуления урона.
- **True Strike** — Характеристика заклинателя для атаки и урона любым оружием, выбор урона излучением, доп. 1d6–3d6 с 5 уровня.

Каждое заклинание — отдельный переключатель в настройках модуля.

## Инструменты ГМа

- **Круг телепортации: прибытие** — персонажи появляются в заданной точке с анимацией и звуком.
- **Круг телепортации: отбытие** — забирает токены с поля списком или сферой заданного радиуса.

Макросы создаются автоматически при загрузке мира.

## Как устроено

- `scripts/spells/` — по файлу на заклинание, контракт `{ id, label, hint, identifiers, migrate(actor), register() }`.
  Каждое заклинание — отдельный переключатель в настройках.
- `scripts/core/` — диспетчер использования заклинаний, карточка урона с кнопкой «Применить»,
  общий модуль «несколько снарядов с атакой на каждый», кэш настроек, миграции.
- Режим проверки данных общий с Features Automation (вариант «Как в Features Automation»),
  либо собственные списки персонажей.

## Ветка `midiqol`

Это сборка под midi-qol: своих подпорок для работы без него здесь нет.

- Преимущество Faerie Fire и помеха Heat Metal — только флаги `flags.midi-qol.*`.
- Mirror Image слушает `midi-qol.AttackRollComplete`, Magic Missile распределяет дротики
  по `midi-qol.preDamageRoll`; перехвата `rollDamage` больше нет.
- Эффекты на чужих персонажах накладывает `MidiQOL.createEffects`, запрос к ГМу не нужен.
- Карточка урона следует настройке автоприменения самого midi.

Без midi-qol модуль не запускается и сообщает об этом в уведомлении. Универсальная версия
живёт в ветке `nomidiqol` — релизы собираются с неё.

## Установка

Скопировать папку модуля в `Data/modules/spell-automation` и включить в управлении модулями.
